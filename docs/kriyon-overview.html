Kriyon

A friendly desktop app that wraps the Claude Code command‑line tool in a clean interface — so you can run several coding sessions at once and actually keep track of them.

The idea in one line

Keep the real terminal underneath (nothing lost), but add a tidy window on top: organized sessions, readable output, clean copy‑paste, and a heads‑up when a session needs you.

What it does for you

🗂️

Many sessions, organized

Run Claude across several projects and branches at once. They're grouped in a sidebar — no more lost terminal tabs.

🔔

Know what's happening

Each session shows its status and a short summary. Get a notification when one finishes or needs your input — without switching to it.

📖

Readable output

A clean "Studio" view lays out the conversation, code, and changes nicely. Prefer the raw terminal? One click to switch.

📋

Copy that just works

Copy code or output and it comes out clean — no random line breaks chopping up your text.

💻

A real terminal

It's a proper terminal too — vim, ssh, and any command work normally. Claude is the star, but the shell is fully there.

⌘

Quick jump

A search box (⌘K) to jump straight to any session or run a command.

How it works (plain version)

  1. You log in once with the normal Claude tool, the usual way. Kriyon never touches your login — it just uses the tool you already have.
  2. You start a session in a project. Kriyon runs the real Claude command for you behind the scenes.
  3. You see two views of the same session: the raw terminal, and a tidy structured version built from Claude's own saved history.
  4. The sidebar keeps watch — status, progress, and notifications — so you can leave a session running and check back later.

The clever part: the real terminal always shows everything, so when Claude adds new features, Kriyon never breaks. The tidy view sits on top as a nice‑to‑have.

Playing by the rules

Kriyon follows Anthropic's terms. The approach is simple:

You use your own Claude login — we never store or pass around your credentials.
We run the official Claude tool unchanged, just in a nicer window.
Normal, hands‑on use — one person, real work, you stay in the loop.
No automation on your subscription. Any future automation will use a separate API key instead.
Not named "Claude" and not pretending to be official — it's "Kriyon, works with Claude Code," with a clear "not affiliated with Anthropic" note.

What we build first vs. later

Version 1

  • Multiple sessions across projects and branches
  • Tidy view + raw terminal, switchable
  • Sidebar status, summaries, notifications
  • Clean copy‑paste
  • Quick‑jump search
  • A side panel showing file changes and usage

Later

  • Review changes → open a pull request → merge, in‑app
  • An automation mode (using your API key)
  • Room for other tools like Codex, side by side
  • Polishing Windows and Linux

What it's built with

Mac first, but able to grow to other systems. Chosen to stay fast and light even with many sessions open.

Tauri (lightweight app shell) Rust (the fast engine underneath) React (the interface) xterm.js (the terminal)

Decisions made

Settled

• Flat, clean look (not frosted glass) — a touch faster for the terminal.
• Branches kept simple — basic create/switch, no extra helpers for now.
• zsh fully supported, and the terminal engine (xterm.js) is confirmed the best fit.
• We build on one branch and keep things lean — no over‑engineering.
