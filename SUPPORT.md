# Getting help

- **Questions and ideas:** ask in [GitHub Discussions](https://github.com/LeafyCode/kriyon/discussions).
  Search first; someone may have asked already.
- **Bugs:** open a [bug report](https://github.com/LeafyCode/kriyon/issues/new/choose). Include
  the steps to reproduce it; a bug we can't reproduce is hard to fix.
- **Feature requests:** open a [feature request](https://github.com/LeafyCode/kriyon/issues/new/choose).
- **Security problems:** follow [SECURITY.md](SECURITY.md). Never use a public issue.

## Problems with Claude Code itself

Kriyon runs your own `claude` CLI. If the same problem happens when you run `claude` in a plain
terminal, it's a Claude Code problem. Report it to Anthropic, not here.

Kriyon is maintained by a small team at [LeafyCode](https://leafycode.com/) in our own time.
There is no paid support, and we can't promise a reply time.
